# 架构与验收说明

## 模块职责

- `src/app.js` 是页面控制器，处理首次浏览器偏好、界面语言和服务器选项、输入校验、锁定交互、异步请求和阶段刷新。
- `src/preferences.js` 独立保存首次识别的浏览器语言，并据此决定服务器可见性和默认值；手动切换界面语言不会改写浏览器偏好。
- `src/network-time.js` 通过当前站点 HTTP `Date`／`Age` 响应头同步 UTC 时间，并用 `performance.now()` 推进时间；它不读取设备日历。
- `src/model-loader.js` 只接收调用方传入的时间，按区域刷新时刻及 180 天阶段配置选择模型，提供游戏内容日期和下一刷新时刻；开服前返回 `not_open`，未打包的组返回 `unsupported`。
- `src/calculator.js` 校验所选组并比较保留与放弃结果，不依赖 DOM 或界面语言。
- `src/viewer.js` 把计算结果映射为建议文字、建议区状态，以及“接受／放弃”按钮的颜色优先级。服务器或配置组变化时由控制器清除当前品阶、变化量、建议和锁定状态；同组每日刷新会保留当前输入和建议。
- `scripts/build.mjs` 验证原始数据并生成运行时多组模型；`scripts/serve.mjs` 提供静态预览资源。

## 游戏术语来源

非中文界面术语仅节选游戏 `TransTable` 中相关字段：`ResourceBasic#item_name#super_compute_deep_calculate_item`（道具名）、`ResourceBasic#item_des#super_compute_deep_calculate_item`（Data Mining、Advanced Metric 等词系）及 `Buffname#buff_intro` 下的 `all_officer_skill_damage_b_p`、`all_officer_skill_avoid_b_p`、`all_damage_b_p`、`all_avoid_b_p`、`all_bullet_damage_b_p`、`all_bullet_avoid_b_p`。简体中文三条属性名按用户指定。

## 页面操作

首次访问按浏览器语言偏好选择界面语言并在本机记录该偏好。简体中文偏好默认国服并显示服务器选择；首次出现服务器位置提示，手动关闭后会记录关闭状态。后续手动切换语言不会改变服务器选项规则；简中偏好切换到繁体中文时，语言旗帜仍显示中国国旗。其他浏览器偏好默认国际服并隐藏服务器选择。简中偏好的服务器选择保存在本机。

阶段状态显示配置组、品阶上限和游戏内容日期。国际服每日于 UTC 00:00 刷新当天内容；国服每日于 UTC 16:00 刷新次日内容。模型使用网络 UTC 时间并按各自开放时刻每 180 天升阶。首次网络时间同步失败会禁用计算并提供重试；后续同步失败会显示网络时间提示，使用最后成功的网络时间锚点，不改用设备日期。页面会在每日刷新与 180 天边界重新核对模型；同配置组日刷新保留当前输入和建议，配置组变化时清空。开服前或缺少配置时，页面显示状态并禁用计算。

三行当前品阶由用户手动输入，必须是 0 到当前上限之间的整数。编辑过程中允许暂时为空，提交时会拒绝空值和非法值。每行可选 −2、−1、0、+1、+2；越过有效范围的选项不会出现，结果自动显示为只读值。

按“计算”后，绿色标题表示建议保留，红色标题表示建议放弃，中性标题表示保留或放弃均可。建议区在结果可用前隐藏；满品时显示完成提示。左侧接受按钮会将新品阶设为当前品阶；右侧放弃按钮保留原品阶。两项都会清空变化量和建议，按钮位置固定，建议对应动作使用绿色或红色突出。概率表不支持的结果仍可比较参考值，并同时显示概率支持提示。

锁定一条属性使用 20 张卡。选择锁定项后先显示确认提示，继续后该属性变化量固定为 0。按 Esc 会按“继续”处理并关闭提示。

## 验证范围

自动检查命令为 `npm test` 和 `npm run build`。当前 `npm test` 的 42 项 Node.js 测试全部通过。测试覆盖模型参考值、输入边界、18 种语言和术语、浏览器偏好、结果建议优先级、网络时钟失败与重试，以及两服 UTC 日刷新与阶段边界。

本轮使用全新 `http://localhost:4411` origin 完成 IAB 验收。首访简体中文默认载入国服配置 20（上限 7），服务器说明保持显示，直到访客手动关闭。临时静态服务器让首次网络时间 HEAD 请求返回 HTTP 503；页面明确提示无法获取网络时间并禁用计算，点击重试后同步成功。以网络响应固定时间 `2026-08-08T20:00:00Z` 验证国服显示 8 月 9 日内容、配置 20／上限 7，国际服显示 8 月 8 日内容、配置 40／上限 11。

语言菜单 18 面旗帜的 SVG 均成功加载；简中浏览器偏好下，繁体中文选项和选中后的旗帜都为 `cn.svg`。选中当前语言会关闭菜单；Tab 可进入选项、Enter 可选择、Esc 会关闭并将焦点返回语言按钮，点击输入框会关闭菜单且保留输入框焦点。简中、英语、阿拉伯语和德语在 320、410、768、1440 像素视口共 16 个组合无横向溢出；410 像素下重置与计算按钮均宽 110.7 像素，结果按钮均宽 163.1 像素；RTL 下接受按钮在左、放弃按钮在右，语言菜单位于视口范围内。

国服当前品阶 6/6/6、三条均增加 1 时显示接受建议和绿色重点按钮；接受后品阶变为 7/7/7 且变化量清空。三条均减少 1 时显示放弃建议和红色重点按钮；放弃后品阶仍为 6/6/6 且变化量清空。后续网络时间同步失败时沿用最后成功时间锚点由单元测试覆盖。非简体中文偏好的服务器显示规则由偏好单元测试和源码检查覆盖；本次 IAB 没有模拟英文浏览器语言偏好。全量 42 项自动测试通过。

网络时间来源为同源网页服务响应的 `Date`／`Age` HTTP 头，精度为秒级；它用于计算刷新日期，不代表 Warpath 官方游戏时钟。

## 模型边界

服务器阶段从网络同步的 UTC 时间计算：阶段序号为 `floor((网络时间 - 开放时间) / 周期)`，配置组与品阶上限按对应步长变化。国服每日 UTC 16:00 开始次日内容，国际服每日 UTC 00:00 开始当天内容。同步失败时首次禁用计算；有成功同步锚点时继续使用该网络时间并提示重试，不读取本机墙上时间。国服和国际服分别使用各自开放时间、刷新边界、来源版本和当前阶段，不合并阶段假设。未打包的配置组返回 `unsupported`，不夹限到最近组。

每个组拥有匹配自身概率分布、目标上限和参考状态的模型。当前参考策略假设三个属性等价值、独立抽取，且放弃整组结果不改变当前状态；保底和追赶效果没有纳入转移。锁定模式只比较已经出现的整组结果，后续参考策略仍按不锁方式计算。当前品阶与配置索引的对应关系及实际服务器选档仍有证据边界；超出概率表支持范围时，参考值比较不代表该配置概率适用于实机。
