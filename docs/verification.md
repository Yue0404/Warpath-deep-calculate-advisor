# 架构与验收说明

## 模块职责

- `src/app.js` 是页面控制器，处理首次浏览器偏好、界面语言和服务器选项、输入校验、锁定交互、异步请求和阶段刷新。
- `src/preferences.js` 独立保存首次识别的浏览器语言，并据此决定服务器可见性和默认值；手动切换界面语言不会改写浏览器偏好。
- `src/network-time.js` 通过当前站点 HTTP `Date`／`Age` 响应头同步 UTC 时间，并用 `performance.now()` 推进时间；它不读取设备日历。
- `src/model-loader.js` 只接收调用方传入的时间，按区域刷新时刻及 180 天阶段配置选择模型，提供游戏内容日期和下一刷新时刻；开服前返回 `not_open`，未打包的组返回 `unsupported`。
- `src/calculator.js` 校验所选组并比较保留与放弃结果，不依赖 DOM 或界面语言。
- `src/viewer.js` 把计算结果映射为纯文本建议和比较值。服务器或配置组变化时由控制器清除当前品阶、变化量、建议和锁定状态；同组每日刷新会保留当前输入和建议。
- `scripts/build.mjs` 验证原始数据并生成运行时多组模型，同时把 Chart.js 打包为本地资源；`scripts/serve.mjs` 提供静态预览资源。

## 游戏术语来源

非中文界面术语仅节选游戏 `TransTable` 中相关字段：`ResourceBasic#item_name#super_compute_deep_calculate_item`（道具名）、`ResourceBasic#item_des#super_compute_deep_calculate_item`（Data Mining、Advanced Metric 等词系）及 `Buffname#buff_intro` 下的 `all_officer_skill_damage_b_p`、`all_officer_skill_avoid_b_p`、`all_damage_b_p`、`all_avoid_b_p`、`all_bullet_damage_b_p`、`all_bullet_avoid_b_p`。简体中文三条属性名按用户指定。

## 页面操作

首次访问按浏览器语言偏好选择界面语言并在本机记录该偏好。简体中文偏好默认国服并显示服务器选择；首次出现服务器位置提示，手动关闭后会记录关闭状态。后续手动切换语言不会改变服务器选项规则；简中偏好切换到繁体中文时，语言旗帜仍显示中国国旗。其他浏览器偏好默认国际服并隐藏服务器选择。简中偏好的服务器选择保存在本机。

模型按网络 UTC 时间选择配置，但页面不展示阶段状态。国际服每日于 UTC 00:00 刷新当天内容；国服每日于 UTC 16:00 刷新次日内容。模型按各自开放时刻每 180 天升阶。首次网络时间同步失败会禁用计算并提供重试；后续同步失败会显示网络时间提示，使用最后成功的网络时间锚点，不改用设备日期。页面会在每日刷新与 180 天边界重新核对模型；同配置组日刷新保留当前输入和建议，配置组变化时清空。开服前或缺少配置时，仍显示 `not_open`／`unsupported` 对应错误状态。

三行当前品阶默认留空并显示灰色占位符，用户手动输入 0 到当前上限之间的整数。编辑过程中允许暂时为空，提交时会拒绝空值和非法值。非法值对应的框线泛红，错误气泡出现在控件上方，修正后恢复；提交多个错误时先聚焦首项，聚焦其他错误框会切换气泡。增减选项读取当前模型对应品阶的概率权重，隐藏零权重及越界结果。锁定项不参与抽取，保持变化量 0。结果自动显示为只读值。

三个词条默认展示开锁按钮，未锁定时显示消耗 5 张深度计算卡。点击开锁会显示渐显的推荐不锁提示；点“继续”或按 Esc 后应用锁定，只保留该项闭锁并显示消耗 20 张。点击闭锁立即解锁，恢复三把开锁及 5 张消耗。消耗行使用用户提供的卡片 PNG。中文属性名在“加深/抵抗”之前换行。重置、切服及配置组变化恢复空输入并清除锁定。计算后以纯文本显示建议，达到满品时显示完成提示；未开放时显示 `not_open` 错误。

升降品概率图表使用当前已载入服务器与配置组的概率数据，显示五种结果（−2、−1、不变、+1、+2）的细柱堆叠分布，每根柱子总计 100%。横轴标明品阶单位，悬浮提示仅显示各段概率。用户可打开数值表查看精确值。Chart.js 通过构建打包为本地资源，页面不依赖 CDN 或后端服务。

自动检查命令为 `npm test` 和 `npm run build`。本轮 48 项 Node.js 测试及构建均通过。测试覆盖计算器、阶段配置、18 种语言与术语、交互输入、浏览器偏好、网络时钟和概率图表；新增真实配置 40 的零概率过滤及锁定不变校验。

本轮在 `http://localhost:4412/Warpath-deep-calculate-advisor/` 完成 IAB 验收，页面无警告或错误。410×582 下核对三个输入默认空值、灰色占位符、中文属性换行、默认开锁和卡片资源。空值提交聚焦首错，点击其他红框切换气泡；负数、小数、指数、文本和超上限值均显示红框及对应气泡，底部错误行保持隐藏，合法值恢复。国服 0–7 品和国际服 0–11 品逐行核对可选增减，均与模型数值表中的正概率结果一致。0 品未锁只可选 +1，锁定后仍显示不变且不可编辑。验证不锁计算及接受结果、锁定提示的继续与 Esc、互斥锁、直接解锁、重置及切服后空输入与 5 张消耗。320 像素宽度下检查 18 种语言，气泡均位于可见宽度内，无页面横向溢出，重置与计算按钮等宽。

概率图数值仍为国服配置 20 的 8 行、国际服配置 40 的 12 行；本轮在 1100×800 桌面检查细柱、横轴“当前品阶（品）”及悬浮的五段概率，汇总行已移除。图表下方说明行已移除，查看数值的入口保留。410 像素宽度下图表弹窗无横向溢出。此前 503 故障注入已验证数值回退及重试恢复，本轮没有修改该加载流程。

这些浏览器数据验证了上述配置及品阶范围；未验证未来 15 品阶段的 UI。网络时间来源为同源网页服务响应的 `Date`／`Age` HTTP 头，精度为秒级；它用于计算刷新日期，不代表 Warpath 官方游戏时钟。

## 模型边界

服务器阶段从网络同步的 UTC 时间计算：阶段序号为 `floor((网络时间 - 开放时间) / 周期)`，配置组与品阶上限按对应步长变化。国服每日 UTC 16:00 开始次日内容，国际服每日 UTC 00:00 开始当天内容。同步失败时首次禁用计算；有成功同步锚点时继续使用该网络时间并提示重试，不读取本机墙上时间。国服和国际服分别使用各自开放时间、刷新边界、来源版本和当前阶段，不合并阶段假设。未打包的配置组返回 `unsupported`，不夹限到最近组。

每个组拥有匹配自身概率分布、目标上限和参考状态的模型。当前参考策略假设三个属性等价值、独立抽取，且放弃整组结果不改变当前状态；保底和追赶效果没有纳入转移。锁定模式只比较已经出现的整组结果，后续参考策略仍按不锁方式计算。当前品阶与配置索引的对应关系及实际服务器选档仍有证据边界；超出概率表支持范围时，参考值比较不代表该配置概率适用于实机。
