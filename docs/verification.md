# 架构与验收说明

## 模块职责

- `src/app.js` 是页面控制器，处理服务器和语言选择、输入校验、锁定交互、异步请求和阶段刷新。
- `src/model-loader.js` 根据区域阶段配置和本机时间选择服务器阶段，加载已打包的概率组和参考值；开服前返回 `not_open`，未打包的组返回 `unsupported`。
- `src/calculator.js` 校验所选组并比较保留与放弃结果，不依赖 DOM 或界面语言。
- `src/viewer.js` 把计算结果映射为建议区的显隐、语义状态和文字。阶段或服务器变化时由控制器清除当前品阶、变化量、建议和锁定状态。
- `scripts/build.mjs` 验证原始数据并生成运行时多组模型；`scripts/serve.mjs` 提供静态预览资源。

## 游戏术语来源

非中文界面术语仅节选游戏 `TransTable` 中相关字段：`ResourceBasic#item_name#super_compute_deep_calculate_item`（道具名）、`ResourceBasic#item_des#super_compute_deep_calculate_item`（Data Mining、Advanced Metric 等词系）及 `Buffname#buff_intro` 下的 `all_officer_skill_damage_b_p`、`all_officer_skill_avoid_b_p`、`all_damage_b_p`、`all_avoid_b_p`、`all_bullet_damage_b_p`、`all_bullet_avoid_b_p`。简体中文三条属性名按用户指定。

## 页面操作

服务器默认为国际服，可切换到国服；选择保存在本机。阶段状态显示当前配置组和品阶上限，并注明按本机时间估算。页面会在下一阶段边界重新加载模型，切换服务器或阶段会清空输入状态。开服前或缺少配置时，页面显示状态并禁用计算，不会用旧模型继续计算。

三行当前品阶由用户手动输入，必须是 0 到当前上限之间的整数。编辑过程中允许暂时为空，提交时会拒绝空值和非法值。每行可选 −2、−1、0、+1、+2；越过有效范围的选项不会出现，结果自动显示为只读值。

提交后，绿色标题表示建议保留，红色标题表示建议放弃，中性标题表示保留或放弃均可。建议区在结果可用前隐藏；满品时显示完成提示。用户可以将结果设为当前品阶，或继续录入下一次结果。概率表不支持的结果仍可比较参考值，并同时显示概率支持提示。

锁定一条属性使用 20 张卡。选择锁定项后先显示确认提示，继续后该属性变化量固定为 0。按 Esc 会按“继续”处理并关闭提示。

## 验证范围

自动检查命令为 `npm test` 和 `npm run build`；当前 29 项 Node.js 测试全部通过。模型测试覆盖每个已打包组的参考值与转移数据；输入测试覆盖整数范围、变化量边界、锁定和重新计算；阶段与加载测试覆盖服务器切换所需的配置边界；国际化检查覆盖各语言所需键与插值；构建校验区域配置、组模型和本地旗帜资源。

IAB 验收覆盖国服配置 20（上限 7）与国际服配置 40（上限 11）、服务器切换及输入清空、结果建议和操作、锁定确认继续与 Esc 关闭，以及当前品阶边界。18 种语言、两个服务器和 1435、768、410、320 像素四种视口共 144 个组合均无横向溢出；旗帜加载和 RTL 排版正常，没有页面或控制台错误。阶段切换时刻按本机时间估算，长时间阶段边界更新另由阶段加载测试覆盖。

## 模型边界

服务器阶段按各自配置的开放时间和 180 天周期估算：阶段序号为 `floor((本机时间 - 开放时间) / 周期)`，配置组与品阶上限按对应步长变化。浏览器 `Date.now()` 只是本机时钟估算，不是官方服务器时间。国服和国际服分别使用各自的开放时间、来源版本和当前阶段，不合并阶段假设。未打包的配置组返回 `unsupported`，不夹限到最近组。

每个组拥有匹配自身概率分布、目标上限和参考状态的模型。当前参考策略假设三个属性等价值、独立抽取，且放弃整组结果不改变当前状态；保底和追赶效果没有纳入转移。锁定模式只比较已经出现的整组结果，后续参考策略仍按不锁方式计算。当前品阶与配置索引的对应关系及实际服务器选档仍有证据边界；超出概率表支持范围时，参考值比较不代表该配置概率适用于实机。
