# 架构与验收记录

## 实现选择与计划

这个工具只有单页输入、静态参考表查询和语言切换。原生 JavaScript ES 模块足以满足需求，免去框架运行时和依赖升级的维护成本；React／Vue 在未来增加多个页面、复杂状态或用户资料时才有明显收益。当前采用静态 HTML、CSS、计算模块和语言模块，Node.js 仅用于测试与打包。GitHub Pages 直接托管构建产物，玩家浏览器完成计算，无需作者提供服务器。

实施顺序为：确认模型目标与证据边界；核验概率和参考状态；实现录入、建议、锁定和连续操作；补齐游戏语言；配置自动部署；独立验证计算、桌面与手机交互和发布后的真实页面。

## 计算与功能验收

- 14 项 Node.js 测试通过。其中计算测试独立检查全部 364 个排序状态的 Bellman 方程和 1081 条交换建议。
- 输入限于三条 0–11 品整数；词条排列不影响等价值模型的状态值。
- 保留／放弃比较未来期望耗卡，本次已经支付的费用不重复计入。
- 构建与页面加载会验证版本、配置组、概率权重和全部状态参考值；概率改变而参考表未更新时拒绝使用。
- 真实 Edge 浏览器验证保留、放弃、等价、满品、概率表外结果、锁定、将结果设为当前、下一次结果、重置、缺失输入和语言记忆。
- 本地通过仓库同名子路径访问，页面及 JSON 正常加载。构建产物不包含原始 Lua 和源清单。
- 18 种语言均有完整非空文案，插值变量一致；阿拉伯语使用 RTL。全语种检查 1435px、768px、390px、320px 视口无横向溢出。
- 浏览器功能验收过程中无非预期控制台错误、页面错误或失败的资源请求。

## 视觉验收

视觉布局参考 [征神魂玉词条数值工具](https://yongjiewujian.net/)：居中窄版工具、紧凑表格、标题后分隔线、清晰的说明层级。配色按需求使用深灰和浅蓝。通过内置 Image Gen 生成完整计算器主屏设计参考，实施后用 `view_image` 比较设计图和桌面、手机、阿拉伯语截图。内置 IAB 内核因 `helper_unknown_error: setup refresh had errors` 退出，改用 Playwright 驱动本机 Edge。桌面以新设计图原生尺寸 1435×1096 检查，响应式覆盖 768px、390px 和 320px。

| 比较项 | 设计依据 | 页面验证与调整 |
| --- | --- | --- |
| 色彩 | 深灰背景、浅蓝文字、浅蓝主按钮 | 固定 #202327 / #292d32 / #c3e0f4 / #90c8ef，无装饰图片 |
| 布局 | 居中单列工具，先对照输入，再阅读建议 | 窄版内容区、三行表格与下方建议，桌面和手机信息顺序一致 |
| 字体 | 明确标题、输入和说明层级 | 居中标题、紧凑控制字号，数字用等宽数字属性；长语种标题正常换行 |
| 表单 | 两组输入按词条逐行比较 | 使用原生下拉控件；锁定条禁改，未录入结果显示空值 |
| 说明 | 标题分隔线、等价值提醒、暂定模型、来源版本 | 全语种显示，模型解释使用可展开的原生 details |
| 作者 | 钥钥、国际服 UID、哔哩哔哩主页 | 简体原文准确，链接与 UID 已在浏览器检查 |
| 响应式 | 手机上仍能逐条比较 | 修复长语种品阶单位撑宽的问题，小屏单位移到输入下方 |

首屏文案与用户要求及设计参考逐项核对。动态建议、锁定说明与连续操作按钮均用于完整计算流程。字体、下拉箭头与 disclosure 箭头使用浏览器原生表现；页面采用指定的平面深灰色。设计中的示例数值仅用于截图比较，首次打开当前品阶为 0，结果留空，防止示例数据被误当作真实洗练结果。

已核验实际实现保留了设计参考的结构、颜色、层级和操作顺序，修复了发现的移动端溢出。截图不作为游戏服务端概率规则的证据。

## 模型边界

目标为三个等价值词条全部达到 11 品。词条独立抽取、当前品阶对应配置索引是暂定假设；保底与追赶未计入。锁定模式只评估已经出现的整组结果，后续期望耗卡依照无锁策略。18 种语言中部分文案为机器翻译，已检查完整性和变量，尚未逐语种由母语玩家审校。
